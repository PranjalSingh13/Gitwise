# Prompt: Triage a GitWise Bug

Analyze the reported problem without assuming the proposed cause is correct.

Input:
- Expected behavior:
- Actual behavior:
- Reproduction steps:
- Error/log output (redacted):
- Relevant files:
- Recent changes:

Return:
1. Most likely category.
2. Evidence directly supported by provided data.
3. Hypotheses ranked by confidence.
4. Missing information needed.
5. Minimal safe reproduction.
6. Proposed fix options and trade-offs.
7. Regression tests.
8. Risks and rollback plan.

Do not invent test results, file contents or line numbers. Never request or repeat real credentials.
