# Glossary

- **AI explanation:** Model-generated explanation grounded in code and available evidence; not automatically verified.
- **Base branch:** The branch a pull request proposes to merge into.
- **Confidence:** Estimated certainty that a finding is correct; distinct from severity.
- **Finding:** A reported issue, risk or analyzer result.
- **Head SHA:** Commit at the tip of the PR source branch that was analyzed.
- **Idempotency:** Repeating an operation does not create duplicate side effects.
- **Installation token:** Short-lived credential issued for a GitHub App installation.
- **LLM:** Large language model used for natural-language analysis or generation.
- **PR:** Pull request.
- **Prompt injection:** Untrusted content attempts to manipulate model behavior.
- **Precision:** Fraction of reported findings that are true positives in an evaluation set.
- **Recall:** Fraction of known positive cases detected in an evaluation set.
- **Risk score:** Summary of configured risk signals; not proof of safety.
- **Static analysis:** Code analysis without executing the program.
- **Webhook:** Event notification sent by GitHub to a configured endpoint.
