# Capstone Submission Checklist

## Proposal
- [ ] Title and abstract approved
- [ ] Problem statement, objectives, scope and methodology reviewed
- [ ] Literature review sources verified and cited
- [ ] Supervisor approval recorded as required by institution

## Software
- [ ] Requirements mapped to implementation
- [ ] Architecture and ER diagrams match the actual implementation
- [ ] Setup instructions tested on a clean environment
- [ ] CI and automated tests run
- [ ] Security and privacy limitations documented
- [ ] No secrets in repository history
- [ ] Demo data uses fake credentials and safe fixtures

## Evaluation
- [ ] Test cases and expected results recorded
- [ ] Scanner evaluation dataset described
- [ ] Metrics calculated from real runs only
- [ ] False positives and false negatives discussed
- [ ] Limitations and future work included

## Final report
- [ ] Use institution's required format
- [ ] Screenshots come from the actual application
- [ ] References are complete and accurate
- [ ] Declaration/certificate use institution-approved wording
- [ ] Plagiarism and AI-use policy followed
- [ ] Presentation and backup demo prepared
