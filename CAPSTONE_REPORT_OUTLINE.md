# Capstone Report Outline

Adapt this outline to the college/university's prescribed format and supervisor guidance.

## Preliminary pages
- Title page
- Certificate / approval page (only in the institution's required format)
- Declaration (use institution-approved wording)
- Acknowledgements
- Abstract
- Table of contents
- List of figures and tables

## Chapter 1 — Introduction
- Background
- Problem statement
- Motivation
- Aim and objectives
- Scope and limitations
- Organization of the report

## Chapter 2 — Literature Review / Existing Systems
- Git and GitHub workflows
- Existing code review and static analysis tools
- AI-assisted programming tools
- Gap analysis and comparison table
- Cite sources accurately; do not claim no existing solution without research.

## Chapter 3 — Requirements Analysis
- Stakeholders and personas
- Functional requirements
- Non-functional requirements
- Use cases and user stories
- Feasibility analysis
- Assumptions and constraints

## Chapter 4 — System Design
- Architecture diagram
- Data flow diagram
- Use-case diagram
- Sequence diagram for GitHub connection and scan flow
- Database ER diagram
- API design
- Security and privacy design
- UI wireframes

## Chapter 5 — Implementation
- Technology stack and rationale
- GitHub App integration
- PR drafting
- Scanner adapters and findings model
- AI bug explanation workflow
- GitWise Academy
- Important implementation decisions
- Screenshots from the real running system

## Chapter 6 — Testing and Evaluation
- Test strategy and environment
- Unit/integration/end-to-end tests
- Scanner test dataset and labeling method
- Precision/recall and false-positive results if measured
- Usability/learning evaluation if conducted ethically and with consent
- Results, failures and limitations

## Chapter 7 — Results and Discussion
- What was implemented
- Evidence against requirements
- Comparison with objectives
- Known limitations and threats to validity

## Chapter 8 — Conclusion and Future Work
- Summary
- Contributions
- Future improvements
- Final reflections

## References and appendices
- Official docs and academic references
- User guide
- Setup guide
- API examples
- Test cases
- Survey/questions only if approved and actually conducted

## Academic integrity
Do not fabricate experiments, survey results, screenshots, approvals or citations. Clearly identify AI-generated assistance according to institutional rules.
